# Decisión del equipo sobre SQL Server

El equipo decidió limitar el ensayo de reemplazo sin interrupciones a Gateway, Users y Pharmacy. SQL Server Express conserva una réplica y estrategia Recreate; su reemplazo queda fuera de ese ensayo, al igual que frontend y observabilidad. Ver [decisión D02](aiops-open-questions.md). Esta decisión define el alcance de la entrega y no acredita continuidad durante el recambio de SQL.
